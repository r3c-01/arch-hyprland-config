## Excluded material

- **`quickshell-control/ui/`:** all 13 QML files and `qmldir` were moved out of the public source tree. Source inspection confirmed no active QML, Lua, Python, shell or Rofi component imported the directory or referenced its component types. Its ownership and redistribution terms remain unknown. The original directory is preserved only at ignored `work/excluded/quickshell-control-ui/`. It is not a runtime dependency of this release; the file-manager backend, QtMultimedia and widget-specific fonts are not required.
- **Inherited Hyprlock variant:** attribution indicated the JaKooLit/SherLock707 source family, but the supplied variant did not exactly match any of the three current pinned upstream configurations checked. Its precise origin was not established. It is preserved only at ignored `work/excluded/hyprlock-unverified.conf`, and is excluded from the public manifest/archive. The replacement described above retains password locking, blurred screenshot backgrounds and date/time display. The old custom user label and visual styling are not retained.

- **`hypr/scheme/current.lua`:** unreferenced generated color table; no generator/source or ownership evidence was established. Preserved only at ignored `work/excluded/color-palette-unverified.lua`; excluded to avoid distributing unnecessary material with unresolved provenance.
- **`quickshell-control/scripts/sysmon.sh`:** an unused alternate Bash sampler whose header identifies another shell. No source or permission evidence was supplied, and no active configuration references it. Preserved only at ignored `work/excluded/sysmon-unverified.sh`. The active control center continues to use the included Python metrics worker.

These exclusions remain local for reversibility. **Do not distribute `work/`, upload the working directory wholesale, or include the excluded copies in a later commit.** `.gitignore`, the source validator and the explicit release-file inventory enforce separate parts of this boundary. The prepared public-source archive includes only the inventory and its listed files.

## Other provenance and external dependencies

The independently written preparation additions are `cava/*.conf`, `scripts/validate`, `tests/test_safety.py`, the release documentation and inventory/verification records. This describes their creation in the preparation session; it does not assign named ownership or a blanket license.

The remaining pre-existing QML interfaces, Python workers, desktop helpers and small Kitty/Rofi/idle/wallpaper settings are classified as **supplied project implementation, authorship not independently established**. A source-header/import/reference audit found no further explicit third-party attribution to resolve in those included files. That absence does not prove original authorship. Do not describe the entire project as written from scratch or apply one upstream license to these unrelated files. Owners/contributors should confirm any additional copied origins before publication. The per-file classification and review limits are in `docs/SOURCE_AUDIT.md`.

Fonts, cursor themes, applications, Qt, Quickshell and system utilities are external dependencies and are not bundled. Optional workspace overview, wallpaper picker, animated-wallpaper launcher and recorder service are also not bundled; see the README. No unverified logo or screenshots are included. The platform text label implies no affiliation.

A project-wide open-source license remains an owner decision for material the owner has rights to license. Its absence is not itself evidence that publication is prohibited, but downstream users should not assume a general reuse grant for unlicensed project material.


## Runtime dependencies versus redistributed content

The [Quickshell](https://quickshell.org/), [Qt](https://www.qt.io/), [Hyprland](https://hypr.land/), [PipeWire](https://pipewire.org/) and [Cava](https://github.com/karlstav/cava) projects supply the runtime/framework capabilities used here. Their executables, shared libraries, package files, fonts and documentation are not redistributed in the source archive. Other command-line applications and session services are listed in README.md. These acknowledgments describe dependencies, not upstream authorship of the project interfaces or endorsement of this repository.

Desktop icon-theme images, notification icons and MPRIS album artwork can be loaded at runtime from applications/providers. None of those runtime images or fonts is bundled; only the 14 verified Phosphor SVG files are distributed as image assets. No logo, screenshot, wallpaper, recording or audio file is included. Runtime downloads do not gain redistribution permission through this project's source licenses.
